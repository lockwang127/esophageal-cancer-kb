# 食管癌知识库领域指南

## 概述

本知识库收录食管癌（Esophageal Cancer）相关的结构化医学知识，采用知识三元组格式存储，便于AI应用和RAG系统集成。

## 食管癌基础知识

### 疾病概述
- **病理类型**：鳞状细胞癌（90%，中国特色）、腺癌（少见）
- **发病特点**：预后差，病死比约80%
- **高发地区**：华北/华中地区（太行山脉附近）

### 危险因素
- 热饮（65℃以上）- IARC 2A类致癌物
- 腌制食品
- 吸烟、饮酒
- 性别：男性发病率约为女性3倍

## 知识域说明

### 1. epidemiology（流行病学）
收录食管癌的流行病学数据，包括：
- 发病率、死亡率统计
- 地理分布特征
- 危险因素分析
- 预后数据

### 2. biomarkers（分子标志物）
收录与食管癌诊疗相关的生物标志物：
- HER2表达状态
- PD-L1表达与CPS评分
- MSI状态与TMB
- 基因突变谱系

### 3. csco_2024（CSCO指南推荐）
收录2024年中国临床肿瘤学会指南推荐：
- 新辅助治疗方案
- 手术适应症与方案
- 晚期系统治疗
- 免疫治疗药物选择

### 4. treatment（治疗方案）
收录食管癌治疗相关知识：
- 手术入路选择
- 围手术期管理
- 放疗方案
- 并发症预防

## 知识库构建原则

1. **循证医学**：优先收录有临床研究证据的知识
2. **中国特色**：关注中国食管癌特点（如鳞癌为主）
3. **指南遵循**：以CSCO指南为主要参考
4. **持续更新**：跟随最新研究进展更新
